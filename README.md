# Dino Quest

A responsive vanilla HTML/CSS/JavaScript learning runner built from the supplied Chrome Dinosaur runner concept.

## Run on Replit

1. Create a new **HTML, CSS, JS** Replit.
2. Upload this folder's contents, preserving the `js/`, `data/`, and `assets/` folders.
3. Set the run command to serve `index.html` (Replit's static HTML template does this automatically).

No build step, package installation, or external game assets are required. Best scores are stored locally in the browser.

## Controls

- Desktop: `Space` / `Up` jumps, `Down` ducks, `P` pauses.
- Mobile: on-screen up/down buttons or tap the game to jump.

Questions are intentionally separated in `data/questions.js` so teachers can extend or replace the bank without touching game code.
